## 2025-05-14 - [Layout and Keyboard Accessibility]
**Learning:** Organizing action buttons in a horizontal toolbar at the top of the window is a more conventional and space-efficient layout for desktop GUI applications, improving the overall visual balance. Descriptive tooltips that include keyboard shortcut hints significantly improve discoverability for power users and accessibility for those relying on keyboard navigation.
**Action:** Always include keyboard shortcut hints in tooltips for core actions and ensure a visible focus state for interactive elements when using custom stylesheets.
