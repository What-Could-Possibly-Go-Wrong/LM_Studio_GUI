## 2025-05-15 - Standardizing Action Buttons
**Learning:** In PyQt6, consistently applying tooltips, keyboard shortcuts, and accessibility attributes (AccessibleName, AccessibleDescription) across all primary action buttons significantly improves both discoverability for new users and efficiency for power users. Using a helper method like `add_btn` ensures this standard is maintained as the application grows.
**Action:** Use a standardized helper for button creation in future PyQt6 projects to ensure accessibility and shortcut coverage.
